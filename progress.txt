## Codebase Patterns
- ExcelJS writeBuffer() requires `as unknown as Promise<Buffer>` cast to satisfy strict TypeScript generics
- Admin pages always gate on token URL param — show "Accesso Negato" if missing, same pattern across all admin pages
- Email functions use RESEND_FROM_EMAIL env var with fallback 'onboarding@resend.dev'; fire-and-forget with .catch() in routes
- Blob paths: config at 'config/valuation-parameters.json', streets at 'streets/<city-slug>.json'
- City slug: lowercase with hyphens (e.g. 'locate-di-triulzi') — use cityToSlug() from @/lib/cities
- ALLOWED_CITIES is the canonical city list in lib/cities.ts — import from there, never redeclare locally
